# Helix.Templates

Project templates for [Helix UI](https://helix-ui-docs.pages.dev/).

```bash
dotnet new install Helix.Templates
dotnet new helix-blazor -n MyApp     # Blazor WebAssembly
dotnet new helix-wpf -n MyApp        # WPF (.NET 8 or later)
```

Each app has the Helix theme (light, dark or system), a layout with navigation, and a ready-made report page:
filters, a data grid with totals and CSV export, preferences remembered per user.
